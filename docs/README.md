# docs/ — 辅助文档手册

- **职责**：承载根 `README.md`（怎么用）与各子目录 `README.md`（文件级手册）之外的
  **辅助文档** —— 设计圣经、进行中的计划、操作手册、存档。
- **约束与工作偏好** → 见 [AGENTS.md](AGENTS.md)。

## 文件索引

| 文件                               | 写什么                                                                             | 读者          | 改哪 / 改后必测                                                                               |
| ---------------------------------- | ---------------------------------------------------------------------------------- | ------------- | --------------------------------------------------------------------------------------------- |
| [ARCHITECTURE.md](ARCHITECTURE.md) | 设计圣经：不变的设计决策、数据流、契约边界、防错清单（F1…F49）                     | 开发者        | 改设计才动它；**不写**文件级清单与样式数值（那些归子 README）。新增防错项按 `F<n>` 续号       |
| [PLAN.md](PLAN.md)                 | 下一步做什么、未立项的研究方向                                                     | 维护者        | 与根 [AGENTS.md](../AGENTS.md) 待办区**分工不重叠**：跨模块短条目在那边，成轮工作在这边       |
| [PUBLISHING.md](PUBLISHING.md)     | 怎么发版（现状 / `.github/` 索引 / 版本号语义 / 发版步骤 / 正文来源 / 发布后复核） | 执行发布的人  | 改 [.github/workflows/](../.github/workflows/) 任一文件后必须同步它                           |
| [releases/](releases/)             | 各版本发布正文存档，文件名 = tag（`v0.8.0.md`）                                    | 使用者 / 历史 | **可选覆盖**：放一份就用它，不放就用 Release Drafter 草稿。旧文件是历史存档，**不再要求补建** |
| [audits/](audits/)                 | 实测报告：一次测量得到的、与代码无关的事实                                         | 维护者        | 只增不改（测量有时间点）；被新测量推翻时**新增一份**并在旧的注明                              |

## 变更影响路由

| 改了                             | 必须同步                                                                                                                                        |
| -------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------- |
| `ARCHITECTURE.md` 的防错清单     | 相关子目录 `README.md` 的「改后必测」+ 根 `AGENTS.md` 活跃坑（只留跨模块、致命的那几条）                                                        |
| `PLAN.md` 的方向被立项/做完      | 根 `AGENTS.md` 待办区（做完的**立即删**，不留 `[x]`）                                                                                           |
| `PUBLISHING.md`                  | 根 `AGENTS.md` 文档地图那一行 + [.github/workflows/](../.github/workflows/) 里的注释                                                            |
| `releases/<tag>.md`              | 无 —— 它是**一次性**的发布正文，写完即存档                                                                                                      |
| 新增 / 改名 / 删掉本目录任一文件 | **同批**改根 `AGENTS.md` 文档地图与本文的索引（`pnpm check:doc-paths` 只扫 `src`/`tests`/`scripts` 裸路径，**扫不到这里的断链**，要跑链接校验） |
