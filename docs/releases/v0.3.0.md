## 修复

- **模型清单不再随设置写入消失**：切语言、改主题、存模型页配置原本会触发宿主重建
  下游 fiber，运行时注入的模型路由被一并丢掉 —— 表现为选择框退化成 `provider/model`、
  composer 停用。现在骨架写进随包 patch，并订阅宿主重载事件重推。重建那一瞬的空窗也被
  守住：先零读推回上一份成功清单，再读目录核对，所以不会再出现「选择框空一下」。
- **重名模型的渠道别名原本静默失效**：凭据报回来的 id 带渠道前缀（`wb/glm-4.6`）时
  算不出同名，`overlaps` 恒为空、别名段从未生成，同名模型仍在所有渠道的号之间轮询。
  修法是收键前剥掉已知渠道前缀 —— 实测 `overlaps` 从 **0 → 12**。
- **启动超时不再等于启动失败**：CPA 常常比 DSH 晚起（实测 54 秒，默认预算 30 秒），
  超时后丢掉「正在起」的记忆会让下一个调用方重新拉起进程，永远在从头等一个已被放弃的
  窗口；症状是面板显示可用、模型清单却空。现在等待可续，且能丢弃已退出的进程。
- **独供模型不再落进 `CPA · xxx` 兜底名**：模型清单由多份读拼成（目录 + 逐凭据供给面），
  各自判成败时会出现「目录齐了、归属没齐」而两边都算成功。现在「就绪」是一个统一判据，
  归属算全才推；且「暂时读不到」与「永远读不到」分开处理，一个坏渠道不会把门永久卡死。
- **重启后第一眼看得到模型**：启动不再等读 —— 直接推上次完整成功过的那份磁盘缓存，
  再后台读新的。此前 DSH→CPA 有约 7.6 秒启动差，而供给面是秒级加载的，
  那个窗口里模型会短暂显示成兜底名。
- **qoder 账号的签到不再丢标签**：判定从「优先看哪个键」改成「任一键是今天」——
  开机补签只写渠道级，账号级可能还是昨天。
- **额度条改画剩余占比**（绿=还有，满格=没用），此前画的是已用占比，与直觉相反。
- **额度字段缺失一律留空**，不再编 0；`DEEPSEEK` 之外也修掉了跨渠道合计的假数。

## 新增

- **四个渠道的模型窗口与图像能力已校准**：CPA 目录不带容量字段（实测 72 条 0 条带值），
  所以真实值只能另取。表按渠道分开存，查不到就落宿主兜底 262K ——
  **宁可显示明确的兜底，也不给别的渠道编一个值**。
  - 出处分两档：官方来源（workbuddy / zcode）与第三方推断（qoder / trae），代码里分开
  - 图像能力**只标确认支持的**：少标只会让附加图片被提前拒并点名模型，
    多标则是图片已发出、provider 中途拒绝，会话卡在反复重试
  - 「不确定」填 1M、「有明确反证」保持不标 —— 前者是猜，后者是推翻事实，代价不同
- **状态与运行时目录尊重 `DSH_HOME`**：此前自己拼 `homedir()/.dsh`，
  覆盖被忽略时零报错，用户看到的是「设置老是不生效」。
- **托管配置显式 `server.host: 127.0.0.1`**：此前 CPA 监听 `::`，
  局域网内不带鉴权即可调用 `/v1/*` 消耗账号额度。

## 工程

内部完成边界重构（P0–P7，十一次 PR），**只搬位置、不改行为**：装配与生命周期拆成
`index` / `boot` / `route-table`，对 CPA 的读写收成 `gateway` 唯一通道，业务规则按域进
`ops/`，渠道知识收进 `channels/` 注册表（面板 / 路由 / 别名 / 生成配置全部派生），
两半共享的类型进 `contracts/`。分层方向由 `check:layering` 在构建期与测试期双重拦。

测试从 0 长到 400+ 例，并新增三条门禁：分层检查、文档路径检查、产物断言。

**升级**：`dsh plugin --profile <profile> add dsh-cpa-switch`，重启 DSH 即生效
（宿主半端不随页面刷新加载）。模型清单在首次重启后需一次交互才写盘缓存，
第二次重启起直接命中 —— 这是已知边界，见 [docs/PLAN.md](https://github.com/cslkkl/dsh-cpa-switch/blob/main/docs/PLAN.md) §2.6.0。
