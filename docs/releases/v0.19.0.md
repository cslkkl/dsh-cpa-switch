## 新功能

- **账号被判死时，面板会说，并给你一个按钮。**
  上游有时会把**凭据**判死而不是封号：token 的有效期还有几周、`refreshToken` 也没过期，
  但服务端已经把那个会话列进黑名单（WorkBuddy 侧的错误码是 `12153`）。
  这种号在面板上**和正常的号长得一模一样** —— `status` 仍是 `active`、`disabled` 是 `false`
  —— 唯一的不同只在 `auth-files` 的 `note` 里。于是你能看到的线索只有
  「这号怎么不出余额」，而该做的事（重新授权一次）界面上一个字都没提。
  - 卡片上出现琥珀色「需重新登录」标签，旁边是「重新登录」按钮；
  - 点它走的是与「添加账号」同一个登录会话 —— 协议上重登旧号与加新号是同一件事，
    落盘按 uid 覆盖，**不会多出一个号**；但弹窗标题会写「重新登录」而不是「添加账号」；
  - 判据只认上游那句文案（`session dead` / `re-login required` / `12153`），
    认不出就**不说话**：误报会让你去换掉一份还能用的凭据；
  - 三条一起跟着受益：签到、跑任务、模型调用在这个号上本来就全都会失败。

- **可以删掉没用的账号了。**
  CPA 本来就有 `DELETE /v0/management/auth-files`，只是官方管理界面没做出来。
  - 卡片按钮行末尾多一个「删除」（弱化样式、位置固定 —— 这一排里只有它不可逆）；
  - 点它弹确认框，**标题带账号名**，正文说清三件事：删的是什么、后果（要重新授权一次）、
    以及**替代方案**（只想让它不参与调度的话用卡片上的开关禁用即可）；
  - 删完会**回读确认**文件真的没了才算成功 —— `200` 只说明请求被接受，
    照它报成功的话界面会抹掉那张卡，下次打开号又回来了、而且一直在参与调度；
  - 同时清掉本地记忆里那个号的启用状态，免得以后用同一个 uid 重登时
    带着上一次的开关状态回来。

## 修复

- 无。这一版只有上面两项新能力。

## 升级

```
dsh plugin --profile <profile> add dsh-cpa-switch
```

装完**重启 DSH** —— 这次新增了一条宿主路由（`/api/v1/cpa/account-remove`），
宿主半端要重新加载；浏览器半端的改动刷新页面即可。
**无配置迁移**：账号状态与偏好文件都不动。

## 复验

- 有被判死的号时：卡片上有琥珀色「需重新登录」+ 一个主按钮；正常的号没有任何标签；
- 点「重新登录」→ 弹窗标题是「重新登录 · WorkBuddy」，走完授权后那个号恢复正常；
- 点「删除」→ 确认框标题带账号名；取消 → 什么都不发生；
- 确认删除 → 那张卡消失；`~/.cli-proxy-api/` 里对应的 `<渠道>-<uid>.json` 真的没了；
- 删除后再打开面板：不会又冒出来（回读确认过）；
- 英文界面：`Sign in again` / `Delete` / `Delete the account "…"?`。

## 版本号说明

取 **minor**：两项使用者可观察到的新能力（一个状态标签 + 一个按钮、一个新动作 + 一条新路由）。
按[发布手册](https://github.com/cslkkl/dsh-cpa-switch/blob/main/docs/PUBLISHING.md)的口径，新增能力走 minor。
