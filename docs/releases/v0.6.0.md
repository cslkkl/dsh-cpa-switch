## 新增

- **面板首屏改用骨架屏**：数据还没到时先摆几张骨架卡（张数按本机上次读到的账号数，
  读不到就用兜底常量），不再是空白。扫光挂在「块」上滑动 —— 挂骨头上时窄骨头只能
  整块亮起再暗下、宽骨头却是滑动，同一张卡里会同时播两种动效。
  - 「添加账号」是**真按钮**、网格始终渲染：骨架只盖「还没到的数据」，不占位、不参与卡数。
  - **加载期汇总一起占位** —— 只占位网格会让数据到达时下面的内容被顶下去。

## 修复

- **zcode 渠道选「关」不再让整轮对话失败**。zcode 的合法词汇表里**没有 `off`**，
  我们从前对所有渠道都发 `off`，在 zcode 上必被 `400` 拒（`code 1210`），
  **整轮对话失败**、而不是「档位不生效」。现在「关」的拼写**按渠道给**：
  zcode 发 `none`，其余三个渠道照旧发 `off`（实测它们接受 `off` 且与 `none` 等效）。
  界面不变，仍是「关 / 开」两项。
- **自动签到开关写成功后不再弹回旧值**。写路径作废缓存时抄的是**宿主**那套键名，
  和浏览器侧真正在用的读键对不上 —— 作废匹配不到任何条目（静默空操作），
  界面便一直显示写之前的值。现在本侧读键收进一处构造器，判据拦住别处手写键名。
- **进度条不再「假报满格」**。
- **卡片高度修正**：从前声明 `222px`、实测 `248px`（算式把内边距算进了 content-box 的
  内容高度）；`numbers` 槽位声明 `36px`、真实内容 `42px`（溢出的 6px 被间距吃掉，
  谁也没看见）。现在六个槽位高度**只有一处来源**（`.card` 上的 `--cpa-slot-*`
  与它们的 `calc()`），并把 `facts` 收成**一行**（卡片因此变矮）。
- **产物断言「Switch 未被包在 label 里」的误报**：该判据已误配两次（CSS 类名
  `headSwitch` 与 `label` 子串被连成一段）。现在锚在产物里的真实写法上，并内建自证。

## 机制

- **浏览器侧读缓存键收成一处**（`src/client/cache-keys.ts`）：键身兼两职（读用它取键、
  写后用它当失效前缀），收在一处才同源。它与宿主 `gateway.cacheKeys` 是**两套独立缓存**
  （页面内 vs 进程内），同名只是巧合 —— 别互相 import。写成功后界面值仍取回读。
- **思考档位的实测报告移入 `docs/audits/`**，并回填引用；本轮全量实测（99 个模型逐个
  对照 `off` / `high`）的结论与边界都在那里。
- 骨架与扫光的参数契约、卡片几何契约、进度条文案各自独立成文件并有判据，
  自定义属性一律带 `--cpa-` 前缀（CSS Modules 不改自定义属性名，撞了不报错）。
