## 新功能

- **左侧栏多了一行「CPA 切换器」，面板可以直接点进去。**
  以前进面板只有一条路：翻到「插件」页、在那张卡片里展开。现在侧栏
  （与「插件 / 自动任务 / 用量统计 / SSH」同一排）多了一行本插件的入口，
  点开之后中间列就是**同一个面板**的整页形态。
  - **两个入口、一份实现**：插件页里那处照旧；侧栏那行渲染的是同一个面板，
    只是外面多一层页面外壳（顶部一行「返回」+ 一列定宽内容）；
  - **字形换成线条的**：侧栏那排官方图标都是 16 格轮廓，所以这一行用轮廓字形
    （弧 = 切号、人物 = 账号，与插件页那枚实心图标同源、不同画法）；颜色取
    `currentColor`，选中态与明暗主题自动跟随；
  - **名字与插件列表对齐**：以前侧栏那行写「CPA 面板」、插件列表里叫「CPA 切换器」——
    同一件东西两个名字。现在统一成后者（英文 **CPA Switch**）；
  - 面板里的东西一个没变：账号、余额、签到、模型勾选、渠道插件更新都还在原处。

## 修复

- **产物断言里那处「假 ctx」其实不会执行注册**（内部测试夹具，不影响已发布的包）。
  它的 `inject(deps, cb)` 是个空函数，于是**包在座位级等待里的注册在断言里一条都不会发生** ——
  一条永远不会红的检查。现在改成真的回调，并补上侧栏那一组断言
  （两处 id 逐字相同、没占官方 id、返回真调一次）。

## 升级

```
dsh plugin --profile <profile> add dsh-cpa-switch
```

装完**重启 DSH**（宿主半端零改动，但浏览器半端与文案变了）。**无配置迁移** ——
模型选择、账号禁用状态、隐藏的模型清单都不变。

## 复验

- 侧栏出现一行 **CPA 切换器 / CPA Switch**，位置在「自动任务」与「用量统计」之间；
- 点它 → 中间列打开整页面板；点顶部「返回」回对话；
- 插件页里那张卡片的入口照旧可用；
- 亮暗两套主题、以及选中态下，那枚线条字形都读得清。

⚠️ 「返回」按钮的真机点击还没走通（高 DPI 缩放下鼠标没命中），已记进待办；
它只有一条路径（`selectPanel(null)`），产物断言里会被真调一次。
