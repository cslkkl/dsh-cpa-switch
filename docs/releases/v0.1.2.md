## 首次可用版本

在 DSH 里管理 CLIProxyAPI（CPA）的账号：看余额、签到、切换账号，并让 CPA 随 DSH 启停。

### 安装与上手

- **一键准备环境**：自动下载 CPA 与四个渠道插件，生成密钥，拉起服务 ——
  装完插件不用手工编辑任何配置文件
- CPA 下载源走自家 Release（上游下载在受限网络下装不上，改走代理）
- 前置条件只有「装了 DSH」

### 账号管理

- **添加账号**：走 OAuth 授权流程
- **启用 / 禁用账号**：改成「选择」语义，去掉容易误解的「使用中」徽标
- 记住用户的选择（意图文件带来源标记，只认面板产生的选择，不认别的写入）
- 四个渠道的账号卡片与余额显示

### 模型路由

- **随包声明 CPA 模型路由**，插件启动时自动备好 `CPA_API_KEY` ——
  装完即可在对话里选到 CPA 的模型

### 修复

- 修复 CPA 可执行文件探测（此前会导致服务中断）
- 修复路由契约违规：同 path 重复注册会让**所有**路由失效，插件完全不可用
- 修复自动安装的 5 处缺陷：渠道启用、密钥持久化、exe 优先、先补环境、ignored 传染
- 补齐缺失的 peer 依赖，修复装完插件不加载
- 面板槽位移到「包含的组件」上方

**升级**：`dsh plugin --profile <profile> add dsh-cpa-switch`，重启 DSH。
