## 新功能

- **模型选择框左边多了一个「我还能花多少」的读数。**
  选模型的那一刻正是余额决定事情的那一刻（选贵的还是便宜的），而面板上的余额
  要两跳才看得到。现在对话输入行里、**模型选择器的紧左侧**是一个小读数：
  一个字形 + 一个数字，回答「当前这个渠道还剩多少」。
  - **只算启用的号**（禁用的号不会被调度到）；积分渠道是硬币字形，
    token 渠道是圆 + T；
  - **不限额改说「不限」、不写数字**：trae 有不限额号时，旁边挂一个合计会被读成
    「你还有这么多」，而上游说的是「这份没有上限」；
  - ⚠️ **读不到 / 还没加载 / 一个号都没凑出来时它是空着的，绝不画 `0`** ——
    编造的 0 会被读成「余额用光了」，比一片空白更糟；
  - **不是本插件的模型的会话里什么都不显示**（别的 provider 旁边挂我们的账本没有意义）；
  - 数据走面板那份读缓存，**零新增请求**；悬停可以看到「哪个渠道、什么单位的合计」。

- **模型下拉里不再每一行都把渠道名念一遍。**
  选择器早就按渠道分组了，组标题就是渠道（`CPA Switch · WorkBuddy`），而行里
  又写一遍 `WorkBuddy · glm-5.3` —— 同一句话说两遍。
  - 现在**组内每行只有模型名**（`glm-5.3`），渠道只由组标题承载；
  - **收起状态的按钮与菜单根行仍带渠道名**（`WorkBuddy · glm-5.3`）——
    那两处不在分组里，不写就没人知道是谁家的模型；
  - 面板「模型」勾选弹窗里的行同步改成模型名，与选择器逐字一致。

## 修复

- **你禁用的号不再被上游按额度悄悄全部打开。** 渠道插件自带的额度生命周期
  （`lifecycle_auto`，默认开）会在每天 09:00 / 21:00 的定时任务之后，把
  「CN 号 + 被禁用 + 额度未耗尽」的号写回启用 —— 它分不清这个禁用是你点的、
  还是它自己因额度耗尽禁的。
  - 症状：**「我没动它，号全亮起来了」**，而「设为唯一」按钮整排消失，
    零报错；
  - 现在面板读到漂移就**按你的选择禁回去**，并说一句「恢复你禁用的 N 个账号」；
  - ⚠️ **只往一个方向主张**：绝不把上游**因额度耗尽**禁掉的号启用回来
    （否则请求会落到一个耗尽的号上）。面板没打开 / 没读到那个渠道时不动手。

- **「模型」勾选弹窗里几十行长得一模一样。** 每行原先交出去的是**渠道名**，
  三四十行全是同一个「WorkBuddy」，用户分不清在勾哪个模型。
  现在每行是模型名，与选择器里那一行逐字相同。

## 升级

```
dsh plugin --profile <profile> add dsh-cpa-switch
```

装完**重启 DSH**（这次改的是宿主半端与浏览器半端两边）。**无配置迁移** ——
模型选择、账号禁用状态、隐藏的模型清单都不变。

## 复验

- **余额读数**：模型选择框**左侧**出现一个字形 + 数字；切到别的渠道的模型时
  字形 / 数字跟着换；trae 出现「不限」而不是一个数。
- **下拉行**：组内每行只有模型名；收起状态的按钮、菜单根行仍带渠道名。
- **勾选弹窗**：每行是模型名（不再是清一色「WorkBuddy」）。
- **禁用意图**：在面板禁用某个号之后，若上游把它重新打开，面板会再禁回去并提示一句；
  因**额度耗尽**被上游禁掉的号不会被启用回来。

## 版本号说明

取 **minor**：一处使用者可观察到的**新能力**（选择器左侧的渠道余额读数）加若干修缺陷
与行为变化（下拉行改裸名）。按[发布手册](https://github.com/cslkkl/dsh-cpa-switch/blob/main/docs/PUBLISHING.md)
的口径，新增能力与行为变化走 minor。

⚠️ **两处补不回来的代价**（`/model` 弹窗与悬停文案）：宿主在渲染槽位之前就算好了
触发位的 `title` / `aria-label`，且 `/model` 弹窗的搜索只匹配行标签、不匹配分组标题 ——
所以**悬停与读屏只拿到裸名**、**打「workbuddy」搜不到该渠道的模型**
（看得到、搜不到）。这是去掉前缀换来「不再重复」的已知取舍，不是缺陷。

⚠️ **正文是手写的，不是草稿**：本版除了合并进来的 PR，还有**直接推到 `main`** 的
产物改动（包清单声明、CI 收口 job），而 Release Drafter **看不见直推的提交** ——
照默认走会漏掉 npm 页面与包内容的那几条。
