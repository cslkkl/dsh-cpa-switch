## 新功能

- **只让常用的模型出现在模型选择器里 —— 面板工具栏上多了个「模型」按钮。**
  选择器里挤着四个渠道的全部模型（本机约百行），而常用的就那么几个。
  现在：点工具栏的「模型」，弹出当前渠道的模型清单，**取消勾选的就不出现在
  DSH 对话界面的模型下拉里**。
  - **勾选的地方在面板、生效的地方在选择器** —— 面板本身照旧列出全部模型，
    否则你没法把取消掉的再勾回来；
  - ⚠️ **不勾 ≠ 删掉、也不等于不能用**：模型在 CPA 那边照常在、接口照常能调，
    只是不在下拉里出现。这条是弹窗里明写的，也是本功能唯一容易误解的地方；
  - 保存后**立即生效**（不需要等下一次目录刷新）。

## 修复

- **勾选保存成功却不生效**（真机实踩）—— 目录护栏把「用户藏掉的行」当成
  「目录读残」原样拦回：面板说保存成功、状态文件也写对了，但选择器里一个都没少。
  护栏现在按（渠道, 裸名）**逐行豁免**被隐藏的模型，而不是整体放行。
- **勾选清单与选择器不是同一批模型**（真机实踩）—— 清单原先读**渠道目录**
  （`glm-5.2`），而推给宿主的行叫 `Trae/trae/glm-5.2`，两边**一个键都对不上**：
  勾了 18 个，选择器里 9 行一个没少，而所有请求都是 200。清单改用
  「**不隐藏的话会被推送的行**」，与推送侧同一个键。
- **同一个模型在 trae 侧有三个条目** —— 上游给同一个模型注册了三种 id 形态
  （裸名 / 我们写的别名 / 上游又给我们别名套一层前缀），27 条 id 其实只有 16 个模型。
  现在**反复剥前缀**得到裸名，并且推给宿主的清单**同一（渠道, 裸名）只留一行**。
- **面板上的「模型」入口读错响应字段** —— 传输层把响应体摊平在结果对象上，
  而类型带索引签名，于是「取 `result.data`」能编译通过、却永远是空：
  表现是**那块界面根本不存在**（而所有请求都是 200、零报错零日志）。
  现在入口**永远立着**，读不到 / 读失败 / 还没有都在界面里说清楚。
- **图标在真实显示尺寸下读不清（30px）** —— 宿主行内图标只画 **30px**、卡片 36px，
  而旧图是细线灰环 + 描边人物：在那个尺寸下人物散成毛边、环糊成一段「C」，
  灰色还被读成「已禁用」。换成**实心圆盘 + 反白人物 + 反白环绕箭头**，与同一排里
  官方插件的实心彩色图标同一族。

## 内部改动

- 模型名的归一（剥渠道别名前缀）收成**一处**实现，宿主写盘与路由侧判定共用，
  避免两边口径漂开（漂开的症状是「用户藏过的模型某天又自己冒出来」，且没有报错）。
- 撤回了一批做错对象的改动：当初按「号」做隐藏，而维护者要的是按**模型** ——
  那批已整体撤回，面板与文档同步回滚，没有留下半截状态。

## 升级

```
dsh plugin --profile <profile> add dsh-cpa-switch
```

装完**重启 DSH**（改的是宿主半端）。**无配置迁移**：模型可见性默认「什么都不藏」，
不勾选就等于现在的行为；新的状态文件是 `~/.dsh/storages/cpa-panel-hidden-models.json`。

## 复验

- **模型入口**：面板每个渠道页签的**工具栏上**有一个「模型」按钮（与
  「刷新 / 全部签到 / 全部任务」同排）；点开列出该渠道的模型，弹窗里说清
  「不勾 ≠ 删掉」。
- **勾选生效**：取消勾选某个模型 → 保存 → **DSH 对话界面的模型下拉里它消失**，
  而**面板里它照旧在**；勾回来 → 保存 → 下拉里它回来。
- **互不影响**：同渠道其它模型不受影响；同名模型在**别的渠道**不受影响。
- **图标**：插件页行内 30px、卡片 36px 磁贴里是一块读得清的实心图形，
  亮暗两张主题都看得清。
