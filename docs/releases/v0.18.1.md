## 修复

- **侧栏入口默认不再显示。**
  `0.18.0` 让它默认开：装上插件，左侧栏立刻多一行。侧栏是**全宿主共用**的一列
  （插件 / 自动任务 / 用量统计 / SSH），插件默认占位是在替用户决定它长什么样。
  - 现在**默认关**：装完侧栏不动，面板从「插件」页进 —— 那条路一直都在；
  - 想要常驻入口的人：面板底部按一下「侧栏入口」，之后跨重启保持；
  - **读不到偏好也按关**（与默认值同向）：一次读失败不会凭空给侧栏加一行，
    而文件里明明写着关；
  - 面板底部那个开关在「还没读到」时按**关**画（仍可点）—— 读失败不该让它变成点不动。

- **产物断言里那条「关得掉」以前是空的。**
  假 ctx 的 `slots.inject` 返回 `undefined`，组件侧兜成空函数，于是「关掉会摘掉那一行」
  在断言里永远成立。现在它真的返回 disposer，并新增一档「宿主说关 ⇒ 那一行真被摘掉」，
  同时钉住 `main`（面板整页）不受这个开关影响。

## 升级

```
dsh plugin --profile <profile> add dsh-cpa-switch
```

装完**重启 DSH**。**无配置迁移**，但有一条要预期：

- 从 `0.18.0` 升级上来、**没按过**那个开关的用户：侧栏那一行会**消失**（文件不存在 ⇒ 新默认）。
  按一下就回来。
- 已经**打开过**开关的用户：文件里是「开」，升级后**仍然是开** —— 你的选择不会被冲掉。

## 复验

- 装好不点任何开关：侧栏**没有**本插件那一行；面板从「插件」页进；
- 面板底部按「侧栏入口」→ 侧栏那一行出现；再关掉 → 立刻消失；
- 关掉后重启 DSH：仍然关着；打开后重启：仍然开着。
