## 新功能

- **侧栏那一行可以关掉了。**
  面板最底下多了一行「侧栏入口」（默认**开**）。关掉之后左侧栏那行不再出现，
  面板只能从「插件」页打开 —— 想给侧栏腾地方时用。
  - **关掉是摘除注册，不是不画**：留一个空按钮会让人点进去，那是更糟的形态；
  - **默认开、坏值也按开**：入口没了比多一个入口难查得多 —— 用户看不到某个东西时，
    没有任何线索指向一个 JSON 文件；
  - 开关状态存在 `~/.dsh/storages/cpa-panel-prefs.json`，与「隐藏模型」同一类（你的意图，
    不是插件派生出来的），重启后保持；
  - 文案：标题只说「是什么」（`侧栏入口` / `Sidebar entry`），说明只说「关掉之后什么样」
    （`关掉后，面板只能从插件页打开`）。

## 修复

- **开关自己会点不动**（本版内修掉，未进过发布包）：`inject` 的返回值被当成 disposer 用，
  而它要 dispose 的是整个 `inject`；读写又按 `result.data.*` 取值，而宿主是**摊平**返回的 ——
  合起来的症状是开关一直显示「开」、点了回弹。两处都按真实契约改掉，判据钉住
  响应体的取值位置（顶层 `{ok, sidebarEntry}`）。

## 升级

```
dsh plugin --profile <profile> add dsh-cpa-switch
```

装完**重启 DSH** —— 这次新增了一条宿主路由（`/api/v1/cpa/panel-prefs`），
宿主半端要重新加载。**无配置迁移**：偏好文件不存在时按「开」，与升级前行为一致。

## 复验

- 面板拉到底：一行分隔线 + 「侧栏入口」开关，默认在手；
- 关掉 → 左侧栏那行**消失**（不是变灰）；点开面板仍能从「插件」页进；
- 再打开 → 侧栏那行回来；
- 关掉后重启 DSH：仍然关着（偏好落盘）；
- 英文界面文案是 `Sidebar entry` / `When off, the panel is only reachable from the Plugins page`。
