# v0.24.1

## 修复

- **模型健康探测改用 CPA 调用密钥，不再把钥匙错误显示成整列「模型请求失败」。**

  探测会真实调用 `/v1/chat/completions`，这一接口只接受 `CPA_API_KEY`，不接受管理接口的密钥。
  此前每发请求都带管理密钥，CPA 返回的同一份 401 被逐模型复制，界面看起来像整个渠道的模型都不可用。

  - 每一发探测现在显式使用调用密钥；缺少调用密钥时直接给出一条可读错误，不再退回管理密钥发无效请求。
  - 收到 401/403 时整轮停止并返回一条鉴权错误，不再继续烧额度，也不伪造剩余模型的逐行失败。
  - 单次探测超时现在一路传到 HTTP 层，且比业务层超时宽 3 秒；慢模型不会再被通道默认的 20 秒提前掐断。

## 升级

```powershell
dsh plugin --profile <profile> add dsh-cpa-switch
```

装完**重启 DSH**（本次只改宿主半端）。
账号、模型可见性、显示偏好与路由缓存均不需要迁移。
