## 新功能

- **`/v1/*` 现在要鉴权 —— 同一台机器上的其它程序不能再白拿你的账号额度。**
  托管配置此前没有 `access.api-keys` 段，`/v1` 不校验任何密钥：端口虽然只监听
  `127.0.0.1`，但**同机的任何程序**都能不带密钥调 `/v1/chat/completions`，
  直接消耗你的账号额度（2026-10-04 实测不带鉴权返回 200）。
  装上这一版：新机器生成的配置直接带调用密钥；**已经跑过一次的老机器**在 DSH 启动、
  CPA 未运行时自动补上这一段。
  - 只补「缺失」：配置里已有 `api-keys` 是**你的**密钥清单，一个字节都不动；
  - 真机实测（重启后）：不带密钥 `GET /v1/models` → **401**，带密钥 → **200**；
    重启后 46 次对话请求**全部 200** —— 模型照常能发、面板读写照常，
    因为两条路各用各的钥匙（调用密钥走 `/v1`，管理密钥走管理接口）。
  - ⚠️ 改的是**宿主半端**，装完要**重启 DSH**；补写只在 CPA **未运行**时做
    （它运行中持有该配置文件、保存时会回写），所以 CPA 常驻不重启的机器
    要等下一次停机窗口才生效。

- **面板上能看见渠道插件的版本，也能一键换新版。**
  以前判断「渠道插件装好了没」只看**磁盘上有没有 dll** —— 有就算装好，于是
  「一键准备环境」点多少次都不会换版本：本机实测停在 10-04 的构建（qoder 约 0.8.45），
  而上游已是 v0.8.66，且你正踩的那个「`developer` 角色被上游拒」正是 0.8.64 修的。
  现在面板上多一行「渠道插件 `v0.8.45 → v0.8.66`」，要换得**你自己点**。
  - **不自动升级**：上游随时可能改行为，静默升级等于把上游的风险直接灌给你；
  - 换之前**先停 CPA**（Windows 上被加载的 dll 改不了名；外部实例一律拒绝、只停自己启的），
    留旧件备份、失败**自动还原**上一版，换完**不自动重启**；
  - 已装版本记在 `~/.dsh/storages/cpa-panel-install.json`（不记就无从判断有没有新版）；
    判「有没有新版」用 **tag 相等**，不解析版本号；没记过 tag 时**什么都不说**，不编。

## 修复

- **开着代理时，插件的下载与查版本全部失效**（症状是 `HTTP 400`，而同一个代理用
  `curl` 却是 200，看着完全像网络问题）。根因是代理路径下 TLS 握手根本没发生，
  明文请求直接打到了代理上。现在代理路径会真正建起加密连接。
- **重载一次插件就整个挂不上**：插件没把 locale 字典的注销函数交还宿主，第二次注册
  直接抛 `already has locale`，界面上只显示「未能完成同步」。
- 面板上「渠道插件」那一行不再与提示块撞按钮名。

## 内部改动

- 就位探测与**配置代际**（「对端要哪一代」对不上时提前提示，而不是等 CPA 启动失败）
  补成正式判据 —— 这条分支此前没有测试，只有真机脚本验过。
- `SetupSession` 增一个「调用密钥现读」的口子：一键准备写配置时把 `access.api-keys`
  一起落盘。

## 升级

```
dsh plugin --profile <profile> add dsh-cpa-switch
```

装完**重启 DSH**：本批改的多数是宿主半端。无配置迁移、无破坏性改动 ——
托管配置里的 `access.api-keys` 段会在首次启动时自动补上（CPA 未运行时）。

## 复验

- **鉴权**：重启 DSH 后看托管配置里出现 `access:` / `api-keys:` 段；不带密钥调
  `http://127.0.0.1:8317/v1/models` 应 **401**，带密钥应 **200**；随后**发一条模型
  消息**应照常成功，面板打开与写操作照常。
- **渠道插件版本**：面板上应出现版本行；点「更新」后按提示等它下载（约 17 MB），
  日志里应看到「停 CPA → 下载 → 校验 → 替换」的顺序。
- **代理**：开着代理时查版本与下载应正常（不再 400）。
- 在 CPA 未运行的机器上，终端应出现
  `托管配置缺 access.api-keys，已写入 CPA_API_KEY（/v1 从此要求鉴权）`；
  已自己配过 `api-keys` 的机器**不应**出现它（判据是「一字节不动」）。

## 版本号说明

取 **minor**：一个安全默认的收口（`/v1` 从不校验到校验，使用者可观察到：不带密钥
调用被拒）加一个新能力（渠道插件可查版本、可一键更新）。按
[发布手册](https://github.com/cslkkl/dsh-cpa-switch/blob/main/docs/PUBLISHING.md)
的口径，行为变化 / 新能力走 minor。

⚠️ 本版含一处**行为变化**：`/v1` 从此要求密钥。如果你有**插件之外**的程序在直连
`127.0.0.1:8317` 调 `/v1/*`（自己的脚本、别的客户端），它们会开始收到 401 ——
把这些调用方加上托管配置里那个 `access.api-keys` 值即可。
