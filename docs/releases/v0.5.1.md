## 修复

- **Trae 卡片的说明行不再显示成「免费」**：那两个字是上游 `plan` 的实测返回（确实叫
  `Free`），但它和相邻渠道的「2 包」排在同一行，而中文三个档位名里只有它没有「版」后缀
  —— 合起来读像在说「这个号是免费的」。现在统一成 **`套餐：免费版`**，
  「基础版」「专业版」同理；ZCode 那行也从 `2 包 · coding-plan` 变成
  `2 包 · 套餐：coding-plan`。
- **README 把 Trae 的余额单位写成「积分池」**：单位只有「积分」与「tokens」两种，
  Trae 和 WorkBuddy / Qoder 一样是**积分**。而「积分池」是**上游插件**对余额**形状**的
  命名（它自己的面板也那么写），被填进了「单位」这一列 —— 而且**中英两份一起错**，
  从首个提交就漂着。现在改成「积分」/ `credits`，并在表下补一行事实：
  Trae 只有一个余额池，上游不给总额与已用。

## 机制

额度这块的文案从前**没有单一出口**，也没有判据 —— 上面两处别扭查下去是同一个根因：

- **说明行原先在卡片的 JSX 里拼**。卡片引了 UI 包（`primitives` 依赖 `clsx`），
  Node 侧 import 不到 ⇒ 「这一行该说什么」**一条判据都写不出来**，Trae 那行就是这么漂的。
  现在收进 `src/client/credit-text.ts`，判据落在 `tests/credit-text.test.ts`。
- **单位 → 文案的映射原先写了两份**（卡片/汇总一对键、动作反馈另一对），
  **两对的值逐字相同**却各自独立。现在只有 `unitTextOf` 一处判定，
  并加了一条护栏：全仓只有 `credit-text.ts` 允许判 `'tokens'`，防第二份长回来。
- **单位类型提到了 `contracts/`** —— 它是跨两半的形状（宿主 spec → 响应体 → 浏览器），
  原先在两半各写一遍。

## 升级

```
dsh plugin --profile <profile> add dsh-cpa-switch
```

装完**刷新页面**即可（本批只动浏览器半端，不必重启 DSH）。
无配置变更、无破坏性改动；说明行的其余行为不变（没有包就不写「0 包」、
档位认不出原样透传、余量未知才加「可用 ?」、「已用」缺失仍是 `—`）。
