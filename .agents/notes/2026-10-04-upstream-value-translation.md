# 决策：上游取值的翻译边界（2026-10-04）

状态：生效

## 问题

英文界面下，TRAE 渠道的账号卡片上出现了中文「免费」（维护者 2026-10-04 实机发现）。

第一反应是给 `plan` 字段加一张映射表。但**怎么确认上游到底返回什么**，
先卡住了：`config.yaml` 里存的是 bcrypt 哈希（F7），拿不到可用的 Bearer。

## 决策

**上游数据不改，只做适配：实测过的值才映射，认不出的原样透传。**

原则本身写在[架构 §4.9](../../docs/ARCHITECTURE.md)（那是不变的边界），
本篇只记这一次的**实测结果**与**判断依据**。

## 实测：上游返回什么

用 DSH 凭据库（`.credentials.yaml`）里的**明文** `CPA_ADMIN_KEY` 直连 CPA，
逐个渠道读 `/accounts` 与 `/credits`：

| 渠道      | `plan` 实测值      | 备注                           |
| --------- | ------------------ | ------------------------------ |
| trae      | **`免费`（中文）** | `/accounts` 与 `/credits` 都是 |
| zcode     | `coding-plan`      | 英文，认不出 → 原样透传        |
| workbuddy | `""`（空串）       | 无 plan                        |
| qoder     | `""`（空串）       | 无 plan                        |

顺带查出 workbuddy / qoder 有大量中文，但**都是用户自己的数据**（昵称
`布吉捣`、套餐包名 `CodeBuddy个人版…`），**不翻译** —— 替用户改他看到的东西
比不改更糟。

## 走过的弯路（值得记）

第一次探测**报了假阴性**：`plan` 显示「字段不存在」。原因是脚本按
`credits.accounts[]` 找，而 TRAE 的返回是 `results[]`（`adapters.ts` 里
trae 的解析器与其它渠道不同）。

于是我一度断定「上游不返回中文」，还差点把映射表整个删掉 —— 依据是
`plugins/trae.dll` 里 grep 到的「免费」二字。可那两个字在 **Go 注释**里：

```
//   unknown（Free 等） → "免费剩余：--"，进度条不猜测
```

**注释 ≠ 枚举。** 是维护者追问「真的是上游返回的吗」才去实测的。

## 映射表里哪些是实测的

`report.tsx` 的 `PLAN_LABEL`：

| 键                                                           | 来源                                                      |
| ------------------------------------------------------------ | --------------------------------------------------------- |
| `免费`                                                       | **实测**（trae 真实返回）                                 |
| `coding-plan`                                                | **实测**（zcode）→ 认不出，原样                           |
| `basic` / `pro` / `premium` / `基础版` / `专业版` / `高级版` | **未实测** —— 来自 dll 里的英文枚举字面量与推测的中文写法 |

未实测的那几条留着**无害**（真实数据里匹配不到，命中也只是正确翻译），
但它们**不是已确认的事实**，别当契约引用。

## 替代方案（强制）

- **直接删掉整张表**：英文界面下中文原样穿透，正是要修的毛病。
- **猜着翻**（把 `basic`/`pro` 都当成必然出现）：看起来更"完整"，实际是把未知
  当已知 —— 上游改枚举时不报错，只是**安静地显示错的字**。
- **连用户昵称一起翻**：越界。用户数据不该被插件改写。
- **不翻译、只提示用户切中文**：把问题转嫁给用户，而根因只是少一张映射表。

## 影响

- 英文界面下 TRAE 卡片显示 `Free` 而不是「免费」。
- 新增上游档位时**最多不好看**，不会显示错的信息。
- 判据在 `tests/adapters.test.ts` 的「上游 plan 值的本地化」组，
  **直接打在被测函数上**（不抄一份表 —— 抄的话实现改了判据照样绿）。
