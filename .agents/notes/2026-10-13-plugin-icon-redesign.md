# 决策：图标改成「实心蓝盘 + 反白人物 + 反白环绕箭头」（2026-10-13）

状态：生效

## 问题

`icon.svg` 一直是「细线灰环 + 小人物」，两版都没解决同一个问题，维护者两次都说不好看。

根因是**尺寸口径错了**，不是画法问题：宿主行内图标**只画 30px**、卡片 36px
（`dsh-client-ui-plugin-manager` 的 `ROW_ARTWORK_SIZE = 30` / `CARD_ARTWORK_SIZE = 36`），
而我一直按 200px 的观感在调线宽与负空间。同一排里官方插件图标又都是**实心彩色**的
（蓝渐变盾牌 + 白勾、蓝圈 + 蓝勾），一枚细线灰环在里面同时输两样：**太细**、**像禁用态**。

具体的读数：

1. 细线灰环在 30px 下糊成一段「C」，灰 `#6B7280` 还会被读成 disabled；
2. 描边人物在 30px 下头只剩 3px 上下，读出来是个毛边点；
3. 旧版那笔直角折角箭头顶点落在**半径 9.01** 上（弧半径 8.5），既不在弧上也不相切。

宿主把图标当 `<img>` 读，坏了**零信号**（静默回落成默认图形），所以几何必须能被量出来。

## 决策

方向不动（人物 = 账号，环绕箭头 = 同渠道切号），换**画法**：

- **外轮廓 = 一枚实心圆盘**：`r=11`、圆心 `(18,18)`，`#5C8EFF → #2A55D0` 竖向渐变
  （与官方插件同一族的蓝）。外轮廓本身就是一块实心，30px 下不散；
- **反白人物**：头 `r=2.9 @ (18,16.1)`，肩宽 `10.0`、底边 `y=24.4`、隆起顶点 `y=20.0`；
- **反白环绕箭头**：半径 `8.0` 的弧，从 `φ=210°` 绕过头顶到 `φ=25°`（顺时针、盖过 185°），
  线宽 `2.9` 圆头帽；`φ=25°` 处一枚实心三角箭头（底距尖端 `4.4`、半宽 `2.05`）。
  两端都收在肩膀附近，读起来是「绕着他转」，不是「浮着一段弧」。

因为整块就是圆盘，**圆盘直径直接等于墨迹窗口**：`r=11 @ (18,18)` ⇒ 墨迹正好 `7–29`
（四周各留 7）。所以**内层 `transform` 整个去掉了** —— 上一版那套
`translate(...) scale(...)` 是为了把 24 格的小图搬进 36 格，现在不需要了。

**判据是量出来的**：把磁盘上那份 SVG 光栅化到 1440×1440（20px/单位），
按 alpha 通道统计墨迹外接框 = `7 / 7 / 29 / 29`，四周各留 7 ✓。

## 替代方案（强制）

- **继续用细线灰环，只是加粗**：30px 下仍是一段细线，且灰色在官方那排实心彩色图标里
  永远显得弱、像禁用 —— 维护者两次否决的正是它。不采用。
- **`Material refresh` 那种大箭头**：官方墨迹窗口只有 22 单位见方，箭头一大，
  环与人物就得让位（实测算过：`φ=45°` 处腿长上限 2.79、`φ=35°` 处 3.92）。
  放进圆盘后这个矛盾消失：反白箭头可以和盘一样大而不越界 —— 这也是选圆盘的理由之一。
- **「两个账号 + 交换箭头」**（语义最直白：两个小人 + 一枚 ⇄）：在 30px 下两个小人
  各只剩 4px，读起来更像「群组/队列」，反而比「一个人 + 环绕箭头」难认。留作备选。
- **「蓝盘 + 白人物 + ⇄」**：在两个尺寸下那枚 ⇄ 都太挤，人物被压扁。留作备选。
- **改用主题色（`currentColor` / CSS 变量）**：宿主按 `<img>` 渲染，这些一律不生效；
  颜色只能是烘死的值 —— 渐变必须写进 SVG 自己。
- **做成多尺寸 `srcset` / 位图**：`package.json` 的 `icon` 只有一个路径，
  宿主也只读一个文件；为一个 30px 图标引入构建产物不划算。
- **换概念（盾牌、钥匙、⇄）**：维护者定的是「人物 + 环绕切换箭头」，没有理由动。

## 影响

- **收益**：30px 行内与 36px 卡片里都是一块清晰的实心图形，和官方那排图标同一族；
  几何更简单（没有内层变换），量测口径也只剩一条：圆盘直径 = 墨迹窗口 7–29。
- **代价**：图标从「中性灰线描」变成**有颜色的实心块**。这是对外观感的取舍，
  也是维护者明确要求的方向（「不好看，重新设计」）。
- **颜色写死在 SVG 里**：`#5C8EFF / #2A55D0` 与官方插件的蓝同族，亮暗两张主题表都看得清。
- **版本号没动**：图标属展示面（与 `locale/*.json` 同规），但它是**纯视觉**改动，
  不改路由、配置键与对外契约 —— 按[发布手册](../../docs/PUBLISHING.md) 的语义该走 patch；
  发不发、什么时候发由维护者定（tag 由所有者推）。
- **未决**：是否定为最终版由维护者拍板；真机复验条目在根 [AGENTS.md](../../AGENTS.md)
  的待办区（宿主读的是包装里的 `icon.svg`，改完要重装 / 重启才换）。
