# 决策：重载空窗先用上一份清单兜底（2026-10-05）

状态：生效

## 问题

`reconcileProfilePatches`（任何设置写入触发）→ 下游 fiber 重建 → 运行时注入的 volatile 清单消失，
重建后的基线里 `providers.cpa` **只有骨架、没有 `models`**。

这段空窗**用户看得见**，不是「慢一点回来」：

- 宿主模型选择器的契约：选中项不在目录里时退化成显示已保存的 `provider/model`
  （用户看到「Qoder · dfmodel」变成「cpa/dfmodel」），且**保持 composer 停用**
  （`dsh-client-ui-model-selection` 的 README「退登」「目录可用性」两节）。
- 空窗长度 = `refresh()` **推之前的全部 CPA 读**：loader 等待 ≤10s、渠道目录 1+N 条读、
  目录稳定检测 ≥250ms（上限 120s）。也就是说「重推」在推之前先等一串读，空窗就是这一串的长度。

这是同一条根因链上的第 4 次：路由永久消失 → 订阅从未注册 → 重推太慢 → **空窗本身可见**。
前三次都在答「值最终会不会回来、回得多快」，没有一次答「回来之前目录里是不是空的」。
链的机制与防错清单在 [架构说明](../../docs/ARCHITECTURE.md) F39，这里只记本次决策。

## 决策

不变量从「最终会回来」改成 **「重载前后可见状态必须连续」**：任何时刻都不许出现
「provider 在、models 空」。四条同时生效：

1. **零读快推** —— 订阅 `app-boot/config-reload` 之后，先把**最近一次成功推上去的清单**原样推回，
   不等任何 CPA 读；随后才起一轮「读目录 → 算别名 → 覆盖」的慢路核对。
2. **读失败回推** —— 渠道目录或模型目录读失败时回推上一份成功清单，而不是什么都不推
   （什么都不推 = 基线一直空着，要等下一次触发才恢复）。
3. **无历史保持空** —— 从来没有成功推过清单时**保持空**，绝不发明清单；
   CPA 未运行记 `idle`，不算失败。
4. **读不全不推也不写** —— 渠道目录新增完整性标记，任一条读失败即视为没读到：
   既不推清单，也不写别名段（别名段是**整段替换**，缺一个渠道就等于删掉 CPA 里已有的别名）。
   渠道目录与别名表**共用同一次读**，免得两处各读一次而互相矛盾。

推清单本身走宿主热更新分支：`providers` 在 `llm-pi-ai` 的 config schema 里是 `.volatile()`
（`z.dict(profile).default({}).volatile()`），只改 config 且除 volatile 外全等的更新
**不 dispose、不重建**（`cordis-plugin-loader` 的 `volatileOnly`）—— 所以「多推一次」的代价
只是一次 update 往返，快推不必犹豫。

推送序号防倒灌：慢路可能比快路后落，序号更旧的清单不许覆盖已经推上去的新清单。

## 替代方案（强制）

- **把清单写进 profile patch 基线**（窗口真正为零）：要改写宿主 profile 的 patch 文件，
  破坏「DSH 宿主零改动」，且用户 patch 与包 patch 会互相覆盖 → 否决。
- **只把重推继续做快**（第 3 次那条路线的延长）：再快也至少一次读往返，窗口仍然可见 → 只解决一半。
- **读失败时就地把手里的读数推上去**：半截读数里同名模型退化成裸名，
  选中项当场从目录里消失，而报错只有一句 4xx → 否决。
- **兜底改成清空清单**（明确告诉用户「暂时没有模型」）：CPA 停一次就清空，
  选择器反而更频繁地退化 → 否决。
- **用 FIFO 队列串行所有推送**（顺带解决并发写同一条目）：慢读最长 120s，
  快推会被排在其后拖到分钟级，空窗反而变大 → 否决。
  只保留「重载路径内快推在前」这条顺序约束，加推送序号兜住倒灌。

## 影响

- **代价**：重载后短时间内清单是**上一份**（可能少了刚加的号、或多了已删的号），
  慢路随后按完整读覆盖。这段时间用户可能选中已失效的模型，表现为一次 4xx ——
  比 composer 被停用轻。
- **收益**：设置写入不再让选择框退化；读失败能自愈；别名不再被半截读删掉。
- **判据**：`tests/route-registry.test.ts` 的「重载空窗」5 例。变异证明：去掉快路径 /
  读不全当读全 / 失败不回推 / 去掉序号，各自都能让对应用例变红。
- **真机验收**：改 `src/` 侧必须 `pnpm build` 后重启 DSH —— 验收动作是写一次设置
  （例如切一次语言）并确认选择框不再退化、composer 不停用。
