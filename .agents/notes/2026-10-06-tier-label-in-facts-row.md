# 决策：说明行的档位带「套餐」前缀，中文档位名统一带「版」（2026-10-06）

状态：生效

## 问题

Trae 的账号卡说明行只有一个词「免费」，而相邻渠道那行写的是「2 包 / 33 包」。
两件事叠在一起，读起来像在说「这个号是免费的」：

- **「免费」不是我们编的**：上游 Trae 插件的 `plan` 字段实测返回中文 `免费`
  （2026-10-04 用明文管理密钥直连 CPA 核实），而它确实是**档位名** ——
  上游 `management.go` 的 `plan` 取选中包的 `display_desc`，回退
  `ProductTypeIdentity(product_type)`，那张表里 `product_type = 0 → "Free"`。
- **它落在说明行里，与「N 包」同类渲染**。说明行同时放「余额的构成（几个包）」
  与「档位」，光有值分不清哪个是哪个。
- **中文三个档位名不成一族**：`免费` / `基础版` / `专业版` —— 只有第一个没有
  「版」后缀，读起来是形容词而不是档位名。

## 决策

**说明行的档位带前缀 `套餐`，中文档位名统一带「版」**：

- `planFree` 由 `免费` 改成 **`免费版`**，与 `基础版` / `专业版` 对齐；
- 新增 `planLabel`（`套餐` / `Plan`），说明行里拼成 **`套餐：免费版`**；
- 前缀与冒号都取自文案表（`planLabel` + `colon`）—— 代码里拼死 `：` 会让英文下
  变成 `Plan：Free`（F28）；
- 英文侧 `Free` / `Basic` / `Pro` 本来就是档位名，**不动**。

于是四渠道的说明行变成：

| 渠道      | 改前                 | 改后                          |
| --------- | -------------------- | ----------------------------- |
| workbuddy | `33 包`              | `33 包`（上游 `plan` 是空串） |
| trae      | `免费`               | `套餐：免费版`                |
| qoder     | `2 包`               | `2 包`                        |
| zcode     | `2 包 · coding-plan` | `2 包 · 套餐：coding-plan`    |

## 替代方案（强制）

- **在进度条槽位写「无总额度，仅显示剩余」**（本仓曾有过这个键 `noTotal`）：
  2026-10-05 已定案删除 —— 那个槽位的语义被钉死为「只放进度条」，无占比时
  **完全空白、只保留高度**（判据 `tests/card-slots.test.ts`）。写字会让同一槽位
  「一会儿是条、一会儿是句子」，切页签时视线踩空。**否决**。
- **在说明行写「仅记余额，不计已消耗」**：Trae 每张卡都会拖这一句，而
  「已用」那格已经是 `—`、下面也没有进度条 —— 两处**已经在表达**同一件事，
  再写一句就是同一状态说第三遍（本仓明确避免）。**否决**。
- **把档位改成「总池子」**：没有数字，答不了「多大」；而且与面板汇总第三格的
  `额度池`（`totalPool` = `size` = **分母**）撞名 —— Trae 恰恰是**没有分母**的渠道，
  这么说方向正好相反。**否决**。
- **只改 `免费` → `免费版`，不加前缀**：改动更小，但「2 包 · 免费版」同行时
  仍然分不清哪个是包数、哪个是档位名。**否决**（前缀是这次真正解决问题的那一半）。
- **Trae 的说明行整个留空**（把档位藏起来）：会丢掉「这台号是 Free 档」这个事实，
  而它解释了为什么余额只有几百；且 ZCode 的 `coding-plan` 本来就在显示档位，
  藏掉 Trae 的会变成同一位置时有时无。**否决**。

## 影响

- 使用者能观察到的变化：Trae 卡片说明行由「免费」变成「套餐：免费版」，
  ZCode 由「2 包 · coding-plan」变成「2 包 · 套餐：coding-plan」。
  属**行为改动**，同批 bump patch 版本号。
- 判据：`tests/credit-text.test.ts`（中英各断言一次，钉住全角 / 半角冒号）
  与 `tests/channels.test.ts` 的「中文上游值映射得到」。
- ⚠️ **`套餐` 里有一个「包」字**：写「Trae 那行不含包」的断言时不能判
  「不含『包』」，要判「不含『N 包』」—— 已在判据里注明（差点写成假红）。
