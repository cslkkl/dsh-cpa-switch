# notes/ — 规则层

继承根规则，见 [../../AGENTS.md](../../AGENTS.md)。

notes/ 特有约束：

- **第 3 行必须是状态行**：`状态：生效 | 被取代 | 已否决 | 已归档`。
- **「替代方案」是强制的**，不是可选项 —— 不记录被打败的选项，下次必然重诉。
- **就地标记归档，不建 `archived/` 子目录**，也不挪动文件（交叉引用会断）。
- **不建索引文件**，也不逐篇列清单。
- 一篇一个决策。想记两件事就写两篇。
- 记「为什么」，不记「怎么做」（那是各模块 `README.md` 的职责）。

命名、结构与骨架见 [README.md](README.md)，不写在这里。
