# 决策：面板加一个侧栏入口（2026-10-19）

状态：生效

## 问题

面板此前只挂在插件页（`plugins.bundle.config`，key = 包名）。维护者想把它也放到
**侧栏**，和 Plugins / 自动任务 / 用量统计 / SSH 并列 —— 也就是"左上角那几行"。

而 2026-10-07 那份决定写的是**「面板只挂插件页」**，理由是"面板是实时操作台，
不是配置项"。所以这是否推翻了那个决定，必须先说清：

- 2026-10-07 拆掉的是 **`settings.plugins.tab`** —— 设置页里的**配置项页签**。
  面板出现在那里，语义确实错位（用户去设置页是去改配置的）。
- 侧栏行**不是**配置项入口：它是宿主给**全局面板**的标准入口，用量统计与 SSH
  都挂在那儿（第三方插件、官方留的公共座位）。面板是实时操作台，正要一个常驻入口。

两条并不冲突：**取消的是"设置页里的配置项页签"，新增的是"侧栏的全局入口"**。

## 决策

在 `sidebar.panellist`（`list`）注册一行，并在 `main`（`keyed`）注册它的落点：

| 座位                | id / key    | order | 内容                     |
| ------------------- | ----------- | ----- | ------------------------ |
| `sidebar.panellist` | `cpa-panel` | 20    | 线条字形（`PanelGlyph`） |
| `main`              | `cpa-panel` | —     | 面板整页（`PanelPage`）  |

三件事绑在一起，缺一个都是静默失败：

1. **两个 id 必须逐字相同**。宿主按侧栏行的 `id` 去 `main` 里找落点
   （`ctx.layout.selectPanel(id)`），找不到**抛在点击处理器里** —— 界面不动、
   只有控制台有声。所以两处都取 `ids.ts` 的 `PANEL_ID`，代码里没有裸字面量。
2. **`order: 20`**：官方四行占 0 / 10 / 30 / 40，20 正好落在自动任务与用量统计之间
   —— 既不抢宿主的门面位（0），也不掉到最后一个。
3. **`ctx.inject(['layout'], …)` 等布局服务**：「返回」要 `selectPanel(null)`。
   座位级等待，**不进导出的 `inject` 数组**（与 `modelDirectories` 同一条口径：
   服务晚到只该挡住这一个座位，不该把插件页那份面板一起挡在门外）。

面板本身**只有一份**（`<Panel>`）：插件页那处与本页共用同一个组件，本页只是外面
多一层页面外壳（一行返回 + 960px 内容列，形状照抄官方页面插件）。

### 字形

侧栏那排官方图标全是 **16 格 outline、`Icon…OutlineRegular`（1px 描边）**，
所以本插件的字形也必须是线条，不能拿插件页那枚**实心蓝盘**塞进去（同一行里
一块实心会立刻显出"不是一族"）。

画法：把 `icon.svg` 的几何**等比换算**到 16 格，弧画成**带宽的轮廓**
（两条同心弧 + 两端半圆端盖），头与肩照原稿顶点 —— 也就是维护者给的那张
"红描边"图，描边改黑。带宽从原稿的 1.05 格放大到 1.25×（3.6 格）是**被 16px
逼出来的**：1.05 格宽 + 两条 1px 描边之间只剩 0.05 格，等于实心。

## 替代方案（强制）

- **把面板挂到 `sidebar.footer.action`**（设置旁边那一排小动作）：那是**一个共享的
  flex 行**，与别的插件的动作抢宽度，而且只有一个图标位、没有文字行 ——
  用量统计插件的注释里写明它正是为此才选了 `sidebar.panellist`。
- **只挂侧栏行、不挂 `main`**：`selectPanel` 对未注册的 key 会抛 ⇒ 点了没反应。
  两者是同一件事，拆不开。
- **复用官方某个 id**（如 `plugins`）：`list` 座的契约写得很清楚 —— 复用官方 id
  **就是占进那一格并替换它**，等于把宿主的功能顶掉。
- **字形继续用实心蓝盘**：30px 行内读得清，但侧栏是 16/18px 的 outline 排，
  一枚实心块在那里既重又不合族（维护者两次指出的正是这个方向）。
- **字形带一个向右上的"尖"**（原稿那个喙）：在 16px 下会读成喇叭口；维护者定的是
  **不带尖**、端点收圆。
- **只做配色变体（用主题色画实心）**：`currentColor` 已经让选中态与明暗主题
  自动跟随，问题不在颜色而在"实心 vs 线条"这个画法。

## 影响

- 收益：面板有了一个**常驻**入口（不用先翻到插件页），与宿主其它全局面板同款；
  插件页那个入口照旧，两处渲染的是同一份 `<Panel>`。
- 代价：注册面多两处（一个侧栏行 + 一个 `main` key），产物断言与
  `tests/client-apply.test.ts` 各多一组判据；侧栏从中段多一行，`order: 20`
  决定了它在自动任务与用量统计之间。
- 判据：`scripts/verify-artifacts.cjs` 的「侧栏行 / main 同名 / 未占用官方 id /
  座位级等待 / 返回选回 null」五条，加 `tests/client-apply.test.ts` 的
  「侧栏入口」一节（含"字形不许写死颜色"）。
- 接线：[index.tsx](../../src/client/index.tsx)（两处注册）、
  [ids.ts](../../src/client/ids.ts)（`PANEL_ID` / `PANEL_ORDER`）、
  [PanelGlyph.tsx](../../src/client/PanelGlyph.tsx)（字形）、
  [PanelPage.tsx](../../src/client/PanelPage.tsx)（页面外壳）。
