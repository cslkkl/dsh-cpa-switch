# 决策：侧栏入口默认收在「更多」里，靠「注册哪一个座」实现（2026-10-26）

状态：生效

## 问题

侧栏顶部那一列插件图标越来越挤（插件 / 自动化任务 / CPA 切换器 / 使用统计 / SSH …）。
宿主在 `0.2.1-rc.3` 给了官方的解法：面板列表末尾一个「更多」按钮，把低频入口折进去。

维护者给本插件的要求很具体：**打开「侧栏入口」开关后，入口默认出现在「更多」里**，
而不是删掉那个开关。

## 决策

入口有**两个落点、互斥**，由偏好 `sidebarPinned` 选一个：

| `sidebarEntry`  | `sidebarPinned` | 注册哪个座                  | 用户看到                     |
| --------------- | --------------- | --------------------------- | ---------------------------- |
| `false`（默认） | ——              | 都不注册                    | 侧栏里没有它，只能从插件页进 |
| `true`          | `false`（默认） | `sidebar.panellist.actions` | 侧栏「更多」菜单里一行       |
| `true`          | `true`          | `sidebar.panellist`         | 栏上一行常驻图标             |

位置在面板底部那行偏好里切（`SegmentedControl` 两档），**只在开关打开时出现**。

**关键取舍：折叠不靠宿主的 pin 回调，靠「我们不注册那个座」。**

## 替代方案（强制）

- **调宿主 `onPinnedChange(PANEL_ID, false)` 把自己收起来**（第一版实装过，已删）。
  宿主的机制本身是给这个用的，`panelPins.unpinned` 也确实会让栏上那一行消失 ——
  但那个回调**只发给 `sidebar.panellist.actions` 的注册者**，而注册者的组件
  **只在「更多」被点开时才挂载**：宿主 `Menu` 的实现是
  `const list = open && (…)`，children 不 open 就不进树。于是「默认收纳」变成
  「用户第一次点开更多之后才收纳」。
  补充证据：即使能调，那个状态还是**内存态**（`createPanelPins` 注释原话：
  held in memory until plugin reload），每次刷新都得重调一次 —— 两重问题叠在一起。
- **两档都注册**（栏上留图标 + 菜单里也放一行）：用户会看到**同一个面板两个入口**，
  而「更多」的意义正是减少重复。
- **不给 UI，位置写死「更多」**：最省，但用户从此**没法把它钉回栏上** ——
  而宿主侧没有别的入口能改面板的 pin（`sidebar` 的 More 菜单当前只由宿主自己的
  entry-customization 渲染，它不列面板）。等于把一个能力换成一个单向门。
- **把 `sidebarEntry` 换成三选一（关 / 更多 / 栏上）**：语义更直接，但要改一个
  已经在用户文件里的字段形状（boolean → enum），迁移成本大于收益；
  而且「关」与「在哪」本来就是两个正交问题，合成一个枚举会让「关掉时位置保留」
  这个行为无处安放。

## 影响

- 偏好文件多一个字段（`sidebarPinned`，默认 `false`）。**老文件缺这个字段时按
  `false` 读** —— 升级后开关为开的用户，入口从栏上收进「更多」，这是新口径本身，
  不是容错方向。
- 路由 `POST /api/v1/cpa/panel-prefs` 现在接受两个可选字段，**一次只改一个**
  （两个都收下来写会顺带改掉调用方没表达的那个）。
- 面板底部多一行「入口位置」，开关关掉时不出现。
- 判据：`tests/ops-prefs.test.ts`（默认值 / 互不联动 / 老文件迁移 / 脏值只丢一格）、
  `tests/sidebar-visibility.test.ts`（位置默认、变化必须通知）、
  `scripts/verify-artifacts.cjs`（两档互斥、开关为关时两侧都摘除、disposer 被接住）。
- **旧宿主兜底**：「更多」那个座是 `0.2.1-rc.3` 才声明的，而 `slots.inject` 在槽位
  **从未声明**时**永远不跑回调** —— 默认档在旧宿主上会变成「侧栏里什么都没有，
  而开关明明是开的」，这是本仓最忌讳的那类静默消失。所以等 2 秒仍未见声明就
  退回栏上那一行（槽位后来声明时会自动摘掉兜底，保持两档互斥）。
  代价：旧宿主上看到的是栏上那一行，不是用户选的「更多」—— 但那是**看得见**的降级。
- **代价**：这一行是**我们自己画的**，样式只用宿主 `MenuItemButton` 的 label
  （peer floor `primitives >= 0.1.7-rc.2` 没有 `current` 属性与对勾图标）；
  顺序用 `order: -10` 排在官方那两行之上。
